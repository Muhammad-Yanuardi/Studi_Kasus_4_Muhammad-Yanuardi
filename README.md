## Penjelasan kode program (penjelasan singkat mengenai fungsi dan kegunaan bagian-bagian kode yang digunakan).
1. Inisialisasi Dictionary (data_buku): Menyimpan data awal buku dalam bentuk key-value (judul, penulis, tahun_terbit).
2. Perulangan Menu (while True): Membuat menu interaktif yang terus berulang sampai pengguna memilih menu keluar (5) dengan perintah break.
3. Menu 1 (Read): Menampilkan data buku saat ini dengan memanggil keynya masing". Pengecekan if "penerbit" in data_buku dipakai untuk melihat apakah penerbit sudah ditambahkan.
4. Menu 2 (Add): Menambahkan key baru ("penerbit") ke dalam dictionary menggunakan input pengguna (data_buku["penerbit"] = penerbit_baru).
5. Menu 3 (Update): Mengubah nilai dari key "penulis" dengan nama penulis yang baru diinput.
6. Menu 4 (Delete): Menghapus key "penerbit" dari dictionary menggunakan perintah del.
7. Menu 5 (Tampilan Akhir): Menampilkan data buku terakhir setelah seluruh proses perubahan selesai.
